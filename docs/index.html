Install or update Grip from https://github.com/spendolas/grip/releases/latest

What happens next

  1. Your agent downloads the latest release, checks it, and installs the bridge into ~/.grip.
  2. You import the plugin in Figma. If you already have it, there is nothing to do.

Needs Node.js 18 or newer. Figma Desktop runs on macOS and Windows; on Linux use Figma in the browser.
